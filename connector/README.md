# connector/

Release artifacts for the Beexy Connector update channel land here:

- `info.json` — update metadata (served so it revalidates)
- `beexy-connector-<version>.zip` — the signed plugin package
- `beexy-connector-<version>.zip.sig` — its detached Ed25519 signature (base64)

Published by the Voxxy release process (see the 0019 repo's `packaging-release-process.md`). Empty until the first signed release.
